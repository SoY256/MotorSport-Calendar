# GT circuit map sources

Track-layout SVGs added for the GT World Challenge, British GT and Intercontinental GT calendars that were not
covered by the original F1DB set. Each file is a single closed centre-line path in a 500×500 canvas, in the same
style as the other files in this folder. Geometry was fetched on 2026-10-22.
